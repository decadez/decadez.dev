第一次使用这类软件，可以先记住一个流程：**安装客户端 → 导入订阅 → 选择节点 → 开启连接 → 实际访问验证**。

本文覆盖 Windows、iPhone 和安卓。配图是标注操作位置的**示意图，并非真实软件截图**；不同版本的按钮名称和位置可能不同，请以实际安装版本为准。

## 先弄清：软件不等于订阅

- **Windows**：使用 Clash Verge Rev，它是仍在维护的 Clash 类客户端。
- **iPhone / iPad**：使用 Shadowrocket，通常被称为“小火箭”。
- **安卓**：使用 FlClash，它也是 Clash 类客户端。

安装软件并不会自动获得可用线路。购买 Shadowrocket 通常只获得软件使用权，不包含节点或流量。你还需要服务方或自建服务提供的**订阅链接、兼容配置文件或单个节点信息**。

开始前，先确认 Wi-Fi 或移动网络本身能正常上网，再准备好适合客户端的订阅。本教程不提供订阅，也不推荐具体服务商。

### 这几个词是什么意思？

- **订阅链接**：用于下载节点列表或配置的地址，常带有 token。它像钥匙一样，应当保密。
- **节点**：一条连接线路，一个订阅里可能有多条。
- **规则模式**：按当前配置决定哪些连接走代理，适合日常使用；效果取决于配置内容。
- **全局模式**：将客户端接管的连接交给选定代理，适合临时排查。
- **直连 / DIRECT**：不经过代理。
- **延迟**：测试响应时间，数字越小通常响应越快，但不保证目标网站一定能访问。

只在可信客户端中导入订阅。分享截图前，隐藏订阅链接、二维码、token 和节点凭据，不要将真实订阅发到公开评论区。

## Windows：Clash Verge Rev

### 1. 下载并安装

打开 [Clash Verge Rev 官方发布页](https://github.com/clash-verge-rev/clash-verge-rev/releases)，选择稳定版并展开 **Assets** 文件列表。

- 大多数 Intel / AMD 电脑选择 **x64**，安装文件名通常包含 `x64-setup.exe`。
- Windows ARM 电脑选择 **arm64** 安装包。
- 不确定架构时，打开 **设置 → 系统 → 关于 / 系统信息 → 系统类型**。
- 不要选择 macOS、Linux 的安装包，也不要下载 `Source code`，那是源代码。

双击安装包，按向导完成安装并打开客户端。缺少运行组件时按官方提示安装。如果系统拦截，先核对下载来源和文件，不要随意关闭安全防护。

### 2. 导入订阅

1. 在服务方页面找到 **Clash / Mihomo 兼容订阅**，复制完整地址。
2. 打开客户端的 **订阅** 页面，将地址粘贴到订阅输入框，点击 **导入**。
3. 部分版本使用 **新建 / 新建订阅 → 远程** 入口；按提示填写名称和地址，再保存。
4. 等待下载完成，点击刚导入的订阅卡片，让它成为当前配置。
5. 打开 **代理** 页面，确认能看到节点或代理组。

![Windows 订阅导入示意：填写订阅地址、点击导入、选中配置](/assets/posts/clash-shadowrocket-guide/windows-import.webp)

> 应复制订阅地址，而不是服务商网站首页、购买页或登录页。服务方提供“一键导入 Clash”时也可以使用，导入后仍要检查结果。

### 3. 选择节点并开启连接

1. 在 **代理** 页面选择 **规则 / Rule** 模式。
2. 在配置用于代理的组里选择一个实际节点，或可靠的自动选择组。
3. 不要将需要代理的组设为 `DIRECT`（直连）或 `REJECT`（拒绝连接）。
4. 在 **首页 / 设置** 找到 **系统代理**，打开开关，并保持客户端运行。
5. 用浏览器访问你需要的服务，再打开普通网站确认网络正常。

![Windows 连接示意：规则模式、可用节点和系统代理开关](/assets/posts/clash-shadowrocket-guide/windows-connect.webp)

**系统代理**适合多数遵循系统代理设置的浏览器和应用。如果浏览器能用，但某些应用不生效，它们可能没有遵循系统代理，可以再按 [官方快速入门](https://www.clashverge.dev/guide/quickstart.html) 考虑开启 **TUN 模式**。TUN 可能需要服务模式及相应权限，新手先不要改动不熟悉的高级设置。

### 4. 不用时怎么关闭？

先关闭 **系统代理**，再退出客户端。退出后普通网站打不开时，到 Windows 系统的代理设置中检查是否仍保留手动代理。

## iPhone：Shadowrocket（小火箭）

### 1. 安装软件

在 App Store 搜索 **Shadowrocket**，核对开发者 **Shadow Launch Technology Limited**，按商店显示的价格购买并安装。

可参考 [Shadowrocket 官方 App Store 页面](https://apps.apple.com/us/app/shadowrocket/id932747118)。是否可下载、售价多少，以你的账号商店地区为准。搜不到时先检查地区可用性。使用自己的 Apple 账号，避免使用陌生人共享账号。

### 2. 导入订阅

1. 复制服务方提供的 **Shadowrocket 兼容订阅链接**。
2. 打开软件，点击首页右上角 **＋**。
3. 类型选择 **Subscribe / 订阅**。
4. 将完整地址粘贴到 **URL**，备注可填“我的订阅”。
5. 点击 **完成 / 保存**，返回首页，等待节点列表加载。

![Shadowrocket 添加订阅示意：类型、URL、备注及完成按钮](/assets/posts/clash-shadowrocket-guide/iphone-import.webp)

如果添加页没有 Subscribe，优先使用服务方的“导入 Shadowrocket”入口，或核对当前版本的订阅入口。扫码时分清**订阅二维码**和**单节点二维码**：单节点可以连接，但不等于订阅，不会自动更新整组线路。

### 3. 开启连接

1. 在首页点选一个可用节点。
2. 将 **全局路由**设为 **配置**；分流效果取决于当前规则，订阅未必自带规则配置。
3. 打开首页顶部的连接开关。
4. 首次连接时，系统会请求添加 VPN 配置，点击 **允许**，完成设备验证。
5. 返回软件确认连接已开启，用 Safari 实际访问目标服务，再检查常用网站。

![Shadowrocket 连接示意：连接开关、全局路由、当前节点和 VPN 授权](/assets/posts/clash-shadowrocket-guide/iphone-connect.webp)

VPN 状态只说明隧道已建立，仍要实际访问验证。部分 iPhone 不会一直在状态栏显示 VPN，可在控制中心或系统设置查看。

需要临时排查时，可将全局路由改为 **代理**测试。日常恢复“配置”前，确认当前配置中有适用的规则。

### 4. 关闭和切换网络

不用时回到 Shadowrocket 关闭连接开关。如果反复自动开启，检查按需连接设置及其他 VPN 软件。切换 Wi-Fi / 蜂窝网络后不通，可关闭再开启，或换节点重试。

## 安卓：FlClash

### 1. 下载并安装

打开 [FlClash 官方发布页](https://github.com/chen08209/FlClash/releases)，选择稳定版，展开 Assets，下载 Android 的 **`.apk`** 文件。

- 多数较新手机可选择 **arm64-v8a**。
- 其他设备按实际架构选择；如果发布页提供 **universal** 通用包，不确定时可选择通用包。
- 不要下载 Windows、macOS 或源代码文件。

打开 APK，系统要求时，仅允许此次使用的下载应用安装软件。不同品牌可能称为“安装未知应用”或“允许来自此来源”。安装完成后可以关闭这项来源权限，不需要关闭系统安全扫描。

### 2. 导入订阅并连接

1. 复制 **Clash / Mihomo 兼容订阅**地址。
2. 打开 **配置 / Profiles**，点击 **＋ / 新建**，选择 URL 或远程订阅导入方式。
3. 粘贴链接，保存或提交，下载完成后选中这份配置。
4. 在代理页面选择 **规则 / Rule** 模式，在代理组中选择可用节点。
5. 回到首页，点击 **启动 / 连接**。
6. 系统弹出 VPN 连接请求时，确认由 FlClash 发起，再点击确定。
7. 用浏览器访问目标服务，再访问普通网站确认网络正常。

![FlClash 操作示意：导入配置、规则模式、选择节点及启动连接](/assets/posts/clash-shadowrocket-guide/android-connect.webp)

底部导航和菜单名称可能随版本、语言变化，请按对应功能操作。同一时间一般只运行一个 VPN，避免与其他代理软件抢占连接。

### 3. 更新和关闭

- **更新订阅**：在配置卡片或菜单里找到“更新”，更新完成后重新选择节点。
- **关闭连接**：在首页停止连接，系统 VPN 图标可辅助确认状态。
- **后台经常断开**：在系统电池设置中允许 FlClash 后台运行。
- **切换网络后不通**：先停止连接，再重新启动。

## 常见问题：按顺序排查

### 导入失败或没有节点

先确认普通网络可用，再检查复制的是订阅地址、链接完整且没有多余空格、格式与客户端兼容。确认订阅未过期；必要时从服务方页面重新复制。

### 节点显示超时 / timeout

更新订阅，换一个节点；检查服务有效期和剩余流量。节点延迟测试只供参考，最终以目标服务实际访问为准。

### 显示已连接，但网站打不开

检查是否选中了实际代理节点，确认当前路由模式和规则。换节点后重新访问；手机同时运行其他 VPN 时，先停用其他 VPN。

### Windows 浏览器能用，其他应用不能用

这些应用可能不遵循系统代理。按官方文档检查 TUN 的服务模式及权限，再考虑启用。

### 手机点击连接没反应

检查系统 VPN 授权是否完成，停用其他 VPN，然后重新打开客户端连接。

### 退出软件后，普通网站也打不开

Windows 检查系统代理是否残留；iPhone / 安卓检查 VPN 是否关闭。先恢复普通网络，再重新连接。

## 日常使用速查

**打开客户端 → 确认配置 → 选节点 → 开启连接 → 实际访问**。不用时关闭连接；线路出问题时先更新订阅、换节点，再检查模式和权限。
